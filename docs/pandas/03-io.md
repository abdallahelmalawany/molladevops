# Reading & Writing Data

pandas reads and writes most data formats through `pd.read_*` functions and `DataFrame.to_*` methods.

| Format | Read | Write | Notes |
|---|---|---|---|
| CSV / text | `pd.read_csv` | `df.to_csv` | Most common; many options |
| Parquet | `pd.read_parquet` | `df.to_parquet` | **Columnar, compressed, typed — best for analytics/ML** (needs `pyarrow`) |
| Feather / Arrow IPC | `pd.read_feather` | `df.to_feather` | Very fast local interchange |
| Excel | `pd.read_excel` | `df.to_excel` | Needs `openpyxl` (xlsx) |
| JSON | `pd.read_json` | `df.to_json` | `orient=`, `lines=True` for JSON Lines |
| SQL | `pd.read_sql` | `df.to_sql` | SQLAlchemy engine or `sqlite3` connection |
| HTML tables | `pd.read_html` | `df.to_html` | Needs `lxml` |
| Pickle | `pd.read_pickle` | `df.to_pickle` | Python-only; **never load untrusted pickles** |
| Clipboard | `pd.read_clipboard` | `df.to_clipboard` | Quick copy/paste from spreadsheets |
| ORC, HDF5, Stata, SAS, SPSS, XML | `read_orc`, `read_hdf`, … | `to_orc`, `to_hdf`, … | Specialised |

## CSV

```python
import pandas as pd
from io import StringIO

csv = StringIO("""id;name;joined;salary;dept
1;Ana;2024-01-15;3200,5;ops
2;Ben;2023-07-01;4100;ml
3;Cy;;NA;ops
""")

df = pd.read_csv(
    csv,
    sep=";",                    # delimiter
    decimal=",",                # European decimal comma
    parse_dates=["joined"],     # convert to datetime
    na_values=["NA", ""],       # extra missing markers
    dtype={"dept": "category"}, # explicit dtypes
    index_col="id",             # use a column as the index
)
df.dtypes.astype(str).to_dict()
# -> {'name': 'str', 'joined': 'datetime64[us]', 'salary': 'float64', 'dept': 'category'}
df.loc[1, "salary"]             # -> np.float64(3200.5)
int(df["salary"].isna().sum())  # -> 1
```

Most useful `read_csv` parameters:

| Parameter | Use |
|---|---|
| `sep` / `delimiter` | `","` default; `"\t"` for TSV; `sep=None, engine="python"` to sniff |
| `header`, `names` | Header row number / provide column names |
| `usecols` | Load only some columns (faster, less memory) |
| `dtype` | Force dtypes per column |
| `parse_dates`, `date_format` | Parse date columns (with an explicit format for speed) |
| `na_values`, `keep_default_na` | Missing-value markers |
| `index_col` | Column(s) to use as the index |
| `nrows`, `skiprows` | Read a subset |
| `chunksize` | Iterate over large files in pieces |
| `encoding` | e.g. `"utf-8"`, `"latin-1"` |
| `compression` | `"infer"` handles `.gz`, `.zip`, `.bz2`, `.xz`, `.zst` |
| `engine` | `"c"` (default, parallel for large local files in 3.1), `"pyarrow"`, `"python"` |
| `dtype_backend` | `"pyarrow"` or `"numpy_nullable"` for nullable/Arrow dtypes |

### Writing CSV

```python
import pandas as pd

df = pd.DataFrame({"a": [1, 2], "b": [0.5, None]})
df.to_csv("out.csv", index=False)                 # don't write the RangeIndex
df.to_csv("out.csv.gz", index=False)              # compression inferred from extension
pd.read_csv("out.csv").to_dict("list")            # -> {'a': [1, 2], 'b': [0.5, nan]}
df.to_csv(index=False)                            # -> 'a,b\n1,0.5\n2,\n'
```

### Large files in chunks

```python
import pandas as pd
import numpy as np

pd.DataFrame({"x": np.arange(10_000)}).to_csv("big.csv", index=False)

total = 0
for chunk in pd.read_csv("big.csv", chunksize=2_500):   # each chunk is a DataFrame
    total += int(chunk["x"].sum())
total                                                    # -> 49995000
```

## Parquet (recommended for analytics & ML)

```python
import pandas as pd

df = pd.DataFrame({
    "user": ["a", "b", "c"],
    "amount": [10.5, 3.0, 7.25],
    "ts": pd.to_datetime(["2026-01-01", "2026-01-02", "2026-01-03"]),
})
df.to_parquet("tx.parquet", index=False)          # keeps dtypes, compressed (snappy)
pd.read_parquet("tx.parquet", columns=["user", "amount"]).shape   # -> (3, 2)
pd.read_parquet("tx.parquet", filters=[("amount", ">", 5)])["user"].tolist()   # -> ['a', 'c']
str(pd.read_parquet("tx.parquet")["ts"].dtype)    # -> 'datetime64[us]'
```

Why Parquet: preserves dtypes, column pruning (`columns=`), predicate push-down (`filters=`), small files, readable by Spark/DuckDB/Polars/BigQuery/Athena. Partitioned datasets: `df.to_parquet("dir/", partition_cols=["year"])`.

## JSON

```python
import pandas as pd

df = pd.DataFrame({"id": [1, 2], "tags": [["a"], ["b", "c"]]})
df.to_json(orient="records")                      # -> '[{"id":1,"tags":["a"]},{"id":2,"tags":["b","c"]}]'
df.to_json("events.jsonl", orient="records", lines=True)   # JSON Lines
pd.read_json("events.jsonl", lines=True).shape    # -> (2, 2)

nested = [{"id": 1, "user": {"name": "Ana", "geo": {"city": "Cairo"}}}]
pd.json_normalize(nested).columns.tolist()        # -> ['id', 'user.name', 'user.geo.city']
```

## Excel

```python
import pandas as pd

df = pd.DataFrame({"a": [1, 2], "b": ["x", "y"]})
with pd.ExcelWriter("report.xlsx") as xw:          # several sheets in one file
    df.to_excel(xw, sheet_name="data", index=False)
    df.describe().to_excel(xw, sheet_name="summary")

pd.read_excel("report.xlsx", sheet_name="data", engine="openpyxl").shape        # -> (2, 2)
list(pd.read_excel("report.xlsx", sheet_name=None, engine="openpyxl").keys())   # -> ['data', 'summary']
```

- In pandas 3, `to_excel` writes **unstyled** output; use `df.style...to_excel()` for formatting.
- The default `.xlsx` reader will change from `openpyxl` to the much faster **`calamine`** engine (`pip install python-calamine`) — pass `engine=` explicitly to avoid the warning.

## SQL

```python
import pandas as pd
import sqlite3

con = sqlite3.connect(":memory:")
pd.DataFrame({"id": [1, 2, 3], "amount": [9.5, 20.0, 3.5]}).to_sql("orders", con, index=False)

big = pd.read_sql("SELECT id, amount FROM orders WHERE amount > ?", con, params=(5,))
big["id"].tolist()            # -> [1, 2]
con.close()
```

For other databases use an SQLAlchemy engine: `create_engine("postgresql+psycopg://user:pass@host/db")`. Use `chunksize=` for big result sets and **always pass parameters** (never format user input into SQL strings).

## Cloud storage & URLs

```python
# no-run — needs network/cloud credentials
import pandas as pd

pd.read_csv("https://example.com/data.csv")
pd.read_parquet("s3://bucket/path/data.parquet", storage_options={"anon": False})   # needs s3fs
pd.read_csv("gs://bucket/data.csv")                 # needs gcsfs
pd.read_parquet("abfs://container/data.parquet")    # needs adlfs (Azure)
```

## Quick recap

- [x] `pd.read_csv` with `sep`, `usecols`, `dtype`, `parse_dates`, `na_values`, `chunksize`.
- [x] `to_csv(index=False)`; compression inferred from the file extension.
- [x] Prefer **Parquet** for typed, compressed, columnar storage (`columns=`, `filters=`).
- [x] `json_normalize` flattens nested JSON; `lines=True` for JSON Lines.
- [x] `read_sql` with parameters; never unpickle untrusted data.
